# 摸鱼助手 FishMate

Windows 托盘应用：健康提醒、资讯摘要、工作痕迹与「摸大鱼」面板。数据保存在本机，单实例运行，支持浅色/深色主题。

仓库：<https://github.com/superlongking111/touchingfishv1.0>

## 特性

- **健康提醒**：喝水、走动、休息、厕所等可配置间隔；右下角 toast，支持稍后静默；同时仅显示一条提醒。
- **资讯**：RSS / JSON 门户热榜 + 基于「今日话题」的资讯搜索；本地去重入库；可选 LLM 生成搜索摘要并托盘推送。
- **摸大鱼**：计时面板、本地内容库浏览、工作痕迹摘要、日报草稿、ZIP 导出。
- **工作痕迹**：监听已配置工作目录的文件事件（元数据与路径，不读取文件正文）。
- **摸大鱼与小摸鱼**：摸大鱼窗口打开期间，小摸鱼提醒暂停计时且不弹窗；关闭后从剩余时间继续。

## 系统要求

- Windows 10 / 11（x64）
- 使用打包版无需安装 Python

## 使用

### 发行版（推荐）

1. 打开 [Releases 页面](https://github.com/superlongking111/touchingfishv1.0/releases)，在最新版本里下载 **`摸鱼助手.exe`**。  
   （若页面提示 “There aren’t any releases here”，说明维护者还未上传安装包，请改用下方「从源码打包」，或自行在本地 `dist\` 使用已构建的 exe。）
2. 运行后托盘驻留，右键打开 **设置** / **摸大鱼**。
3. 在 **设置 → 内容** 填写 **今日话题**；需要更好的搜索摘要时可配置 **模型 API**；可点击 **立即抓取并筛选** 填充本地内容库。

### 从源码运行

```bash
git clone git@github.com:superlongking111/touchingfishv1.0.git
cd touchingfishv1.0
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
python run.py
```

## 今日话题：做什么、不做什么

| 环节 | 行为 |
|------|------|
| **资讯搜索源** | 用你在设置里填的「今日话题」作为检索词，向搜狗资讯等发起搜索（见下方「会访问哪些网络」）。 |
| **后台抓取** | 启动后会在随机间隔（默认约 35–90 分钟）自动跑一轮；也可在设置里 **立即抓取并筛选**。未填话题时，搜索类来源会跳过，门户/RSS 仍可抓取。 |
| **托盘自动推送** | 每轮抓取结束后，若产生 **话题搜索的一句话摘要** 且当日推送未达上限（默认 6 次），会弹 **一条** 内容 toast（摸大鱼窗口打开期间不弹）。 |
| **摸大鱼内容库** | 门户/RSS 条目以标题 + 短摘录入库，供 **看看别的** 随机浏览；**不会**对每条门户热榜再调模型扩写。 |

话题字符串保存在本机数据库 `%LOCALAPPDATA%\FishMate\fishmate.db`，不会写进 Git 或打进 exe。

## LLM（模型 API）：配置后怎么被消费

模型为 **可选**。Base URL、模型名、超时等写在 **本机数据库**；**API Key 只存在 Windows 凭据管理器**（服务名 `FishMate` / 用户名 `llm_api_key`），不会出现在仓库、日志或导出 ZIP 的明文里。

### 会调用模型的场景（需已填 API Key）

| 场景 | 触发方式 | 发给模型的内容 | 结果怎么用 |
|------|----------|----------------|------------|
| **搜索一句话摘要** | 后台内容轮次中，对「今日话题」搜到的新结果做汇总 | 话题文本 + 若干条候选的 **标题、URL、摘要片段**（每条摘要截断，约数百字内） | 生成弹窗 **标题 + 40–80 字摘要** 与阅读原文链接，写入本地库并可能 **托盘推送** |
| **连接测试** | 设置里点测试 | 仅发送 `ping` 类极短请求 | 界面提示是否连通 |
| **日报草稿** | 仅在 **摸大鱼** 里你主动点生成日报 | 当日工作痕迹：**时间、事件类型、路径末几段**（不含文件正文）+ 你在界面填的 **备注** | 弹窗展示草稿，你可复制修改；**不会自动发送邮件** |

### 不会调用模型的部分

- RSS / B 站 / 头条等 **门户热榜** 入库与「看看别的」浏览：只用抓取到的标题与 RSS/摘要字段做短预览，**不**走模型排序或扩写。
- **健康提醒** toast：与模型无关。
- **工作痕迹监听**：只记录路径、事件类型、时间等元数据；**不**把磁盘文件内容送给模型（日报也只传元数据聚合）。

### 未配置或调用失败时

- **没有 API Key**：搜索摘要仍可通过 **本地兜底**（用最新命中条的标题/摘要拼一条）写入库；体验弱于模型汇总。日报走 **本地聚合模板**（界面会注明未调用模型）。
- **模型超时/报错**：当次搜索摘要可能跳过模型步骤；可在设置增大 Timeout 后 **立即抓取** 重试。抓取报告里会提示异常类型（不打印 Key）。

### 请求发往哪里

HTTP 请求发向你配置的 **OpenAI 兼容 Base URL**（默认模板为 `https://api.openai.com/v1`，可改为自建或第三方网关）。**密钥与话题不会发往本项目的 GitHub**；是否到达 OpenAI/自建服务取决于你填的 URL。

## 邮件（SMTP）：边界说明

| 存储位置 | 内容 |
|----------|------|
| 本机数据库 | SMTP 主机、端口、登录用户名、默认收件人等 |
| Windows 凭据管理器 | SMTP **密码**（`FishMate` / `smtp_password`） |

**只有**你在 **摸大鱼 → 导出** 向导里填写主题/正文并点 **确认发送** 时，才会用 SMTP 发出邮件（附件一般为导出的 ZIP）。应用 **不会** 在后台自动发信，也不会把 API Key 或数据库打包进邮件。

## 敏感信息与隐私边界

```
┌─────────────────────────────────────────────────────────────┐
│  摸鱼助手.exe / python run.py  （同一 Windows 用户共用）      │
├─────────────────────────────────────────────────────────────┤
│  %LOCALAPPDATA%\FishMate\fishmate.db                        │
│    话题、提醒、内容库、工作痕迹元数据、LLM/SMTP 非密钥字段      │
│  %LOCALAPPDATA%\FishMate\exports\  （导出 ZIP，本地）         │
├─────────────────────────────────────────────────────────────┤
│  Windows 凭据管理器 · 服务名 FishMate                         │
│    llm_api_key · smtp_password                              │
├─────────────────────────────────────────────────────────────┤
│  不会写入 Git / 不会打进 Release exe                         │
└─────────────────────────────────────────────────────────────┘
```

| 数据类型 | 是否离开本机 | 说明 |
|----------|--------------|------|
| API Key / SMTP 密码 | 仅在你配置的 LLM URL 或 SMTP 服务器上使用 | 不落库明文、不进仓库 |
| 今日话题、邮件地址 | 随 LLM/SMTP/搜索请求到你选择的第三方 | 自行评估供应商与合规 |
| 工作目录文件 **内容** | 默认 **不** 读取、不上传 | 痕迹仅为路径与事件类型；敏感扩展名可在策略中忽略 |
| 源码调试与打包 exe | 同用户 **共用** 上述目录与凭据 | 在本机测 exe 会看起来像「已经配好」；换电脑或新用户则为空配置 |

卸载或「恢复出厂」：可删除 `%LOCALAPPDATA%\FishMate\` 并在凭据管理器中删除 `FishMate` 相关条目（会清空设置与本地库）。

## 会访问哪些网络（与 LLM 无关部分）

- 你在 **内容来源** 中启用的 RSS、JSON 接口、门户页、搜狗/Bing 等 **搜索** URL。
- 点击 toast / 摸大鱼中的 **阅读原文** 会在系统浏览器打开对应站点。

以上请求 **不** 经过 FishMate 的 GitHub 仓库；抓取频率受后台间隔与来源失败退避限制。

## 项目结构

```

fishmate/
  app.py            # 应用与托盘
  domain/           # 领域逻辑

requirements.txt
```
